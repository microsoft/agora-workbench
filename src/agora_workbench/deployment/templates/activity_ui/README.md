# Activity UI

This directory was generated by `agora-workbench-deploy init --target activity-ui`.

From the scaffold output directory:

```bash
docker network inspect agora-activity >/dev/null 2>&1 || docker network create agora-activity
docker compose -f activity_ui/docker-compose.yml up -d --build
```

Open <http://127.0.0.1:8030> to view activity. Stop the service with:

```bash
docker compose -f activity_ui/docker-compose.yml down
```

MCP servers publish to the UI by setting `ACTIVITY_UI_URL=http://activity-ui:8030` and joining the external
`agora-activity` Docker network.
